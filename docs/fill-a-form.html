Guides

Fill a job application form

Fill every field the extension can match in one go. Then review the form and submit it yourself.

Filling works on supported and enabled sites.

#From the form

  1. Open the application. A Fill with TalentProfile button appears above the form.
  2. Click it. A Fill this form? dialog opens.
  3. Click Fill form. Click Cancel to stop.

The dialog belongs to the extension, not to the job site. Nothing is filled before you click Fill form.

When it finishes, a tooltip shows how many fields were filled and skipped.

If your profile is incomplete, the tooltip says Your profile is incomplete — fill is partial. Click Complete profile → to add the missing data.

#From the popup

  1. Open the popup on the application tab.
  2. Click Fill visible fields.

The button shows progress, for example Filling 3/7…. Some forms add fields after the first ones are filled. The extension then fills again and reports Discovered new fields after fill with the number of passes.

#With a shortcut

Assign a key to Fill all visible fields with TalentProfile. See Shortcuts.

The shortcut fills at once, with no confirmation dialog.

#Read the result

The popup reports Filled X, skipped Y, not in profile Z, and failed N when something failed.

ResultMeaning
FilledThe field now holds a value from your profile or saved answers.
SkippedThe field was left as it was. It already had a value or the right answer, the match was too uncertain, no option matched, or the field did not respond in time.
Not in profileYour profile has no value for this question. A cover letter is one example.
FailedThe extension could not write to the field.

Fill skipped fields yourself, or insert a value with the picker. Your answers are saved for next time. See Saved answers.

#CV upload

File fields for a CV or résumé are filled with the CV saved in your TalentProfile.

#Before you submit

Check every answer. The extension never submits the application.
