TalentProfile Autofill docs

TalentProfile Autofill is a Chrome extension. It fills job application forms from your TalentProfile.

#What it does

  • Fills a whole application form from your profile and saved answers.
  • Inserts one value or a saved note into the focused field.
  • Saves the answers you give, so the next form needs less typing.
  • Never submits an application. You review and submit it yourself.
